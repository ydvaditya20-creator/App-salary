# App-salary

A Kotlin-based salary management app for tracking employee salaries, pay breakdowns, and payroll-related records.

## Overview

This project is built primarily in Kotlin and includes a lightweight HTML front-end. It is designed to help users manage salary information efficiently, including monthly pay summaries, deductions, bonuses, and net salary calculations.

## Features

- Employee salary tracking
- Monthly and overall salary overview
- Add/update/remove employee information
- Track deductions, allowances, and bonuses
- Calculate net salary automatically
- Clean and simple user interface
- Easy to extend for payroll automation

## Tech Stack

- Kotlin
- HTML
- Android app development workflow

## Prerequisites

Before running this project, make sure you have:

- Android Studio installed
- JDK 8 or newer
- Kotlin support enabled
- An emulator or physical Android device

## Installation

1. Clone the repository:

```bash
git clone https://github.com/ydvaditya20-creator/App-salary.git
```

2. Open the project in Android Studio.

3. Sync the Gradle files.

4. Run the app on an emulator or device.

## Usage

1. Open the app.
2. Add employee details.
3. Enter base salary and any allowances/deductions.
4. Review monthly salary reports and totals.
5. Save and update records as needed.
